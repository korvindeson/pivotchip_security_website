PHASE 04 Live Target Execution
The platform fires the generated exploits against a live version of the application. An active Authentication Manager continuously monitors sessions and automatically logs back in if the application terminates the connection during the attack phase. All attacks and findings are passed to 3-rd party tool for advanced automated testing.
