Three stages:

Stage A loads a finished static scan into Burp. Every route, recorded request, finding, and testable parameter is seeded straight into the site map, scope, and audit issues. No crawl, no traffic.

Stage B adds the review Burp cannot do. A tester sends any request or response to an external LLM harness that maps the URL to source, traces input to sink, and returns a calibrated verdict citing real file and line evidence.

Stage C drives Burp the other way. The harness starts programmatic active audits from chat, captures every issue through a handler, deduplicates them, and folds them back into one corroborated dataset.
