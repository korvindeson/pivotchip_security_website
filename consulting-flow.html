Five stages:

Stage A — reads every line of source code. Discovers every way untrusted data enters the system, every secret, every route, every database operation, and every AI agent surface.

Stage B — deploys the application to a pre-running VM. An AI-driven agent reads docs and manifests, plans the deployment with an LLM, executes it over SSH, and feeds live connection info into the pipeline.

Stage C — generates and executes targeted security tests. Custom exploit attempts are generated from the static map and run against the deployed application to separate real vulnerabilities from noise.

Stage D — collects and correlates runtime evidence. Server logs are pulled or pushed into a sqlite store, correlated to active tests via X-Test-Id, and enriched with live database schema intelligence.

Stage E — delivers the bottom line. Correlates all static, dynamic, and runtime evidence, scores each finding with a transparent rubric, and produces an offline dashboard the whole team can use.
